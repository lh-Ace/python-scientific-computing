# Python Scientific Computing — Course Repository

**Status:** Scaffold prepared; learner has not begun Lesson 01.01.  
**Audience:** Complete beginners in Python, eventually progressing to advanced scientific computing and scientific software engineering.  
**Home base:** ChatGPT course HQ, with this repository as the durable record.

## Mission

Learn Python from first principles, then become independently capable of building, validating, visualizing, documenting, and optimizing mathematical software. Later subjects include numerical linear algebra, ODEs, PDEs, probability, statistics, machine learning, and Python/native-language integration.

**Curriculum before applications.** Applications enter only after the relevant concepts have been taught. The course does not skip fundamental topics to serve a currently useful project.

## Start here

1. Read [`docs/SETUP.md`](docs/SETUP.md) (uses your existing `uv` installation).
2. Read [`docs/SYLLABUS.md`](docs/SYLLABUS.md) and [`docs/LEARNING_PROTOCOL.md`](docs/LEARNING_PROTOCOL.md).
3. Open [`lessons/01-python-foundations/01-01-running-python/README.md`](lessons/01-python-foundations/01-01-running-python/README.md).
4. Keep your answers and thought process in that lesson's `journal.md`; make incremental Git commits.

## Public vs private

Prefer a **private** GitHub repository while assignments and personal reflections are in progress. No license has been chosen for the course's original content. We can decide later whether, and under what license, to publish. **No outside book text, exercise solutions, or full third-party repositories are included in this scaffold.**
