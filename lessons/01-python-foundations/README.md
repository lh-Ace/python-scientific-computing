# Module 01 — Python foundations

**Entry condition:** No previous Python knowledge required. Mathematics beyond elementary arithmetic is not assumed.

## Planned order

| Lesson | Concepts |
| --- | --- |
| 01.01 Running Python | programs, terminal, source files, expressions, `print`, prediction |
| 01.02 Values and arithmetic | integers, floats, operators, precedence, type inspection |
| 01.03 Variables and names | binding, assignment, naming, mutable vs immutable intuition |
| 01.04 Strings and output | quotes, interpolation, formatting, user-readable output |
| 01.05 Decisions | comparisons, booleans, if/elif/else |
| 01.06 Repetition | while/for, range, progress, stopping conditions |
| 01.07 Functions | parameters, return values, local names, contracts |
| 01.08 Collections | lists, tuples, dictionaries, sets, iteration |
| 01.09 Program structure | decomposition, reusable files, imports introduction |
| 01.10 Errors and files | exceptions, traces, simple file read/write |
| 01.11 Independent mini-lab | integrative task using only taught foundations |
| 01.12 Module examination | prediction, construction, debugging, explanation |

This order is provisional at the granularity of lessons: prerequisites and review may justify adding sub-lessons without skipping concepts.

Readings start with Think Python 3e, Fangohr's Introduction to Python for Computational Science and Engineering, official Python docs, and selected Berkeley CS61A materials. Always follow the references attached to the lesson currently being studied, not the entire advanced catalog at once.
