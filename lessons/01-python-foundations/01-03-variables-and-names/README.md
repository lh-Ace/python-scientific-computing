# Lesson 01.03 — Variables and Names

**Status:** In progress  
**Module:** 01 — Python Foundations  
**Prerequisites:** Lessons 01.01 and 01.02

## Why this lesson exists

Until now, our programs have operated primarily on numerical literals written directly into expressions.

Variables allow programs to associate meaningful names with values, reuse information, and update calculations without repeatedly writing the original values.

In Python, assignment binds a name to an object. Understanding this relationship is essential for later topics such as functions, collections, scope, and program design.

## Learning objectives

By the end of this lesson, the learner should be able to:

1. Create and use variable names.
2. Explain the assignment operator `=`.
3. Distinguish assignment from mathematical equality.
4. Explain name binding and reassignment.
5. Trace programs containing multiple assignments.
6. Identify valid and invalid variable names.
7. Understand case sensitivity and basic naming conventions.
8. Describe the difference between changing a binding and changing an object.
9. Debug basic naming and assignment errors.
10. Independently implement a small program using variables.

2. Calculate and display area.
